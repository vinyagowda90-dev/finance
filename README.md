# 💰 Finance Investment Analytics Dashboard

A Machine Learning powered Finance Analytics Dashboard built using Python, Streamlit, Plotly, and Scikit-Learn.

The project analyzes investor behavior, investment preferences, risk appetite, expected returns, and financial decision-making patterns using the Finance Investment Dataset.

---

## 🚀 Features

### 📊 Dashboard
- Total Investors
- Average Age
- Gender Distribution
- Investment Preferences
- Key Financial Insights

### 📈 Exploratory Data Analysis
- Age Analysis
- Gender Analysis
- Investment Avenue Analysis
- Investment Objective Analysis
- Duration Analysis
- Expected Returns Analysis
- Information Source Analysis
- Correlation Heatmap

### 🤖 Machine Learning
Implemented Algorithms:
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

### 🏆 Model Comparison
- Accuracy Comparison
- Precision
- Recall
- F1 Score
- Radar Charts
- Model Leaderboard

### 👥 Investor Segmentation
- K-Means Clustering
- PCA Visualization
- 3D Cluster Visualization
- Investor Personas

### 🎯 Recommendation System
Personalized investment recommendations based on:
- Age
- Risk Appetite
- Investment Duration
- Financial Objectives

# 📥 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/finance-investment-analytics.git
```

Move into the project folder:

```bash
cd finance-investment-analytics
```

Install dependencies:

```bash
pip install -r requirements.txt
```

# ▶️ Running the Application

```bash
streamlit run app.py
```
